# 暖暖農場（happyFarm）

皮克斯風 3D 療癒農場養成網頁遊戲，PC 與手機瀏覽器都能玩。規劃文件在 [`docs/`](docs/00-專案總覽.md)。

**線上試玩**：https://wenbatman33.github.io/happyFarm/ （網址加 `?dev=1` 開啟 DEV 微調工具）

推到 `main` 會由 GitHub Actions 自動建置並部署（`.github/workflows/deploy.yml`）。

## 目前進度：M0–M6 完成（M5 社交為本機模擬版，Supabase 待接）

- Three.js 皮克斯風光影：Neutral 色調映射、柔和陰影、N8AO 環境光遮蔽、Bloom、暗角
- 晝夜與季節跟現實時間同步（夜晚窗戶亮燈、螢火蟲；秋天楓紅落葉）
- 主角（程式建模佔位）：點擊移動、A* 尋路、動作佇列、拖曳連續操作
- 種田：翻土 → 播種 → 澆水 → 收成，作物用時間戳成長（離線也會長）
- **房屋周圍除草**：三段式拔草手感、連擊、季節雜草（落葉堆、蒲公英、積雪）、Lv6 鐮刀
- 柯基「麻糬」：跟隨、閒晃、摸摸、每日挖寶、晚上回狗屋睡覺
- **手推除草機**（試玩開放，正式 Lv45）：有重量感的推動、割草條紋、側邊噴草屑、引擎聲與震動
- **牧場**：乳牛「花花」閒晃吃草，點牠可以餵牧草、刷毛、擠牛奶；割草會收集牧草
- **M1**：14 種作物、30 格田（買地＋清荒地拿木材石材）、堆肥與有機肥、郵筒訂單板、房屋修繕 T2、新手引導（奶奶的信＋3D 箭頭）
- **M2**：捏人（6 種髮型、體型、配色、草帽）、4 選 1 寵物（柯基挖寶／橘貓抓田鼠與午睡／垂耳兔吃草／小鴨潑水）、親密度解鎖、幼年→少年→成年、換裝
- **M3**：農場手帳（每日任務、每週挑戰、30 階季節手帳、圖鑑、32 個成就）、加工坊 10 種食譜、果園 8 種果樹、夜間花、巨型作物、紅頂農舍 T3
- **M3 第二批**：溫室（任何季節都能種、三期擴建）、工具箱（澆水壺、鋤頭、大鐮刀、鎬、斧、除草小機器人）、室內裝潢（最多 6 個房間、43 件家具、舒適度）、雙層農莊 T4、風車莊園 T5；濃密草毯、野草叢、蓬鬆樹冠
- **M4**：37 種作物（四季補齊）、19 種加工配方、13 個節慶（春節紅包、年菜訂單、煙火、節慶商店）、月曆印章卡、月份主題、週末市集與流浪商人、小鎮主線 12 章、回流保護、背景音樂與環境音、PWA（安裝、離線、通知）、存檔碼匯出匯入
- **M5（本機模擬）**：好友碼、拜訪好友農場（幫忙除草澆水、偷菜、放草惡作劇）、好友對你做的事、愛心商店；Supabase 後端與前端介接已寫好（`supabase/`、`docs/10-Supabase-部署.md`）
- **M6 內容補完**：池塘與水生作物（小鴨會游泳）、牆面藤蔓與修枝剪、收養多隻寵物、服裝工坊、咖啡廳訂單、蜂箱與蜂蜜、望遠鏡與流星許願
- 等級、休息加成、背包賣出、本機存檔

## 開發

```bash
npm install
npm run dev
```

開啟 http://localhost:5188

## 操作

| 功能 | PC | 手機 |
|---|---|---|
| 移動 | 點地面／WASD | 點地面 |
| 互動 | 點目標／Space | 點目標 |
| 連續操作 | 按住拖曳 | 手指拖曳 |
| 旋轉鏡頭 | Q／E | 兩指旋轉 |
| 縮放 | 滾輪 | 兩指縮放 |
| 選種子 | 1–4 | 工具列 |
| 農場手帳 | J | 📔 按鈕 |
| 除草機 | R 開關，WASD／按住滑鼠推著走，Esc 收起 | 點 🚜，按住畫面往想去的方向推 |
| 好友 | F | 👥 按鈕 |
| 進屋、工具箱 | 點房子 | 點房子 |
| 室內佈置 | 「🔨 佈置」，R 旋轉，Esc 取消 | 同左（按鈕旋轉） |
| 設定、存檔匯出 | 右上 ⚙️ | 右上 ⚙️ |

## DEV 微調工具

開發模式（或網址加 `?dev=1`）按 `` ` `` 鍵、F2，或點右下角齒輪開啟：
HUD 與場景物件直接拖曳、光影與時段預覽、時間快轉、天氣與季節切換、狀態觸發，調好後按「💾 匯出」取得 JSON。
