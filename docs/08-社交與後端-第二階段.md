## 2. 後端選型

| 方案 | 優點 | 缺點 | 建議 |
|---|---|---|---|
| **Supabase** | Postgres（經濟資料適合 SQL）、內建帳號登入、資料列權限、Edge Functions、Realtime、免費額度夠起步 | 冷啟動延遲 | ✅ 建議 |
| Firebase | 生態成熟、推播整合好 | NoSQL 做經濟查詢較麻煩、費用較難預估 | 備選 |
| Cloudflare Workers ＋ D1 | 邊緣運算、便宜 | 帳號登入要自己做 | 規模大了再考慮 |

登入方式：Google、Apple、Email 魔法連結。**不收集不必要的個資**。

## 3. 伺服器權威模型

| 動作 | 處理方式 |
|---|---|
| 收成、偷菜、購買、升級 | 伺服器驗證（時間戳、數量、金幣），客戶端先樂觀顯示，失敗再回滾 |
| 翻土、播種、澆水、除草 | 客戶端批次送出動作紀錄（每 10 秒或切換分頁時），伺服器抽查合理性 |
| 時間 | 所有成長計算以伺服器時間為準；客戶端開局時校正時差 |
| 異常偵測 | 每小時金幣、XP 超過合理上限 3 倍時標記審查 |

### 3.1 單機存檔轉雲端

第一次登入時把本機存檔上傳，伺服器檢查合理性（等級與遊玩天數是否相符），通過後綁定帳號。只能綁一次。

## 4. 社交功能

### 4.1 好友

- 好友碼、QR code、邀請連結；上限 100 人。
- 好友列表顯示每個人農場上「有成熟作物可偷」「有草可幫忙除」的小圖示——這是開心農場讓人一直想點進去的關鍵。

### 4.2 拜訪農場

進入好友的 3D 農場，看到對方的房屋、寵物、裝飾。對方的寵物會跑過來聞你、搖尾巴（親密度越高越熱情）。

### 4.3 幫忙（正向互動）

| 動作 | 雙方獎勵 | 上限 |
|---|---|---|
| 幫忙除草 | 你：XP＋愛心；對方：雜草直接進背包 | 每位好友每天 5 次，每天總共 30 次 |
| 幫忙除蟲 | 同上 | 同上 |
| 幫忙澆水 | 你：愛心；對方：作物解除乾燥 | 同上 |
| 送禮 | 每天送 1 份種子或肥料 | 每位好友每天 1 次 |
| 訂單互助 | 好友可以幫你補訂單缺的作物 | 每天 3 次 |

### 4.4 偷菜（懷舊玩法，可在設定關閉）

| 規則 | 值 |
|---|---|
| 保護期 | 作物成熟後 30 分鐘內不能偷 |
| 每塊地最多被偷 | 20%（主人至少保留 80%） |
| 同一位好友 | 每塊地只能偷 1 次 |
| 每天偷菜上限 | 20 次 |
| 看門寵物 | 依 `02 §2`，有 20–30% 機率被發現：偷菜者被寵物追著跑的滑稽動畫，什麼都沒拿到，並在主人農場留下「被抓到」紀錄 |
| 通知 | 用幽默的方式通知主人：「橘子發現阿明鬼鬼祟祟摸走了 2 顆番茄 🍅」 |

### 4.5 惡作劇：放草、放蟲（開心農場經典）

- 每天 3 次，可以在好友農場放雜草或小蟲。
- **設計反轉**：主人拔掉「好友放的草」時，獎勵是一般雜草的**兩倍**，還會看到是誰放的。惡作劇變成一種另類的送禮，不會讓人真的生氣。

### 4.6 社群目標

- 全服季節目標：例如「全服一起收成 1,000 萬顆南瓜」，達成後所有人拿獎勵。
- 巨型作物大賽排行（好友榜＋全服榜）。
- 小鎮廣場（主線第 11 章）：可以看到其他玩家的角色與寵物在廣場閒晃，做表情互動。

## 5. 資料模型（初版）

| 資料表 | 主要欄位 |
|---|---|
| `users` | id、暱稱、外觀、建立時間 |
| `farms` | user_id、等級、XP、金幣、房屋階段、存檔 JSON、schema_version、updated_at |
| `plots` | farm_id、格座標、作物、播種時間、濕潤到何時、被偷數量 |
| `weeds` | farm_id、格座標、種類、生成時間、放草者 id（可為空） |
| `pets` | farm_id、種類、名字、親密度、成長階段、服裝 |
| `inventory` | farm_id、物品 id、數量 |
| `friendships` | user_a、user_b、狀態、建立時間 |
| `social_log` | actor、target、動作（偷菜、幫忙、放草…）、數量、時間 |
| `push_subscriptions` | user_id、endpoint、keys、偏好設定 |

## 6. 推播

- Web Push（VAPID），伺服器排程。
- 預設只開兩種：作物成熟、寵物想你（3 天沒上線）。其他（被偷菜、好友幫忙）預設關，玩家自己開。
- **每天最多 2 則**，晚上 22:00 到早上 08:00 不推。
