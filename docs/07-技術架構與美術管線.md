## 1. 技術棧

| 層 | 選擇 | 理由 |
|---|---|---|
| 建置 | Vite ＋ TypeScript | 開發伺服器快、型別安全，資料表多的遊戲特別需要型別 |
| 3D | Three.js（r17x） | 已定案；生態成熟 |
| 後製 | `postprocessing`（pmndrs）＋ N8AO | 環境光遮蔽是「微縮模型感」的關鍵 |
| 模型壓縮 | glTF ＋ Meshopt、貼圖 KTX2 | 手機下載量與記憶體 |
| UI | HTML／CSS 疊在 canvas 上（輕量 Preact） | 文字清晰、無障礙友善、響應式好做 |
| 動畫補間 | 自寫 tween ＋ Three.js AnimationMixer | 骨架動畫走 Mixer，UI 與物件彈跳走 tween |
| 音效 | Howler.js | 手機音訊解鎖、音效池 |
| 存檔 | IndexedDB（idb-keyval） | 容量大、非同步 |
| PWA | vite-plugin-pwa | 離線可玩、加到主畫面 |
| DEV 工具 | lil-gui ＋ TransformControls | 見 §7 |
| 農曆 | 農曆轉換套件（例如 lunar-javascript） | 節慶日期 |

│  ├─ render/             # 光影、材質、後製、品質分級
│  ├─ ui/                 # HUD、選單、對話框
│  ├─ save/               # 存檔、版本遷移、匯出匯入
│  ├─ data/               # JSON 資料表：crops、pets、furniture、festivals、chapters、orders

│  ├─ dev/                # DEV 微調工具（正式版不打包）
│  └─ net/                # Phase 2 後端介面（Phase 1 先接本機假實作）

## 3. 時間與存檔模型

### 3.1 用時間戳，不用 tick

每個會隨時間變化的東西只存「開始時間」和「參數」，目前狀態由 `now` 即時算出來：

```ts
// 作物狀態由時間推算，離線多久都不需要補跑模擬
interface PlotState {
  cropId: string;
  plantedAt: number;       // 播種時間（毫秒）
  growthMs: number;        // 基礎成長時間
  wetUntil: number;        // 濕潤到何時；之後以 0.6 倍速成長
  weedIds: string[];
}
```

- 乾燥期間的減速，用「濕潤時段」和「乾燥時段」分段積分算出實際成長進度。
- 雜草生成：`區域亂數種子 ＋ 上次清理時間 ＋ 每 90 分鐘一個生成時段`，讀檔時一次算出所有應該存在的草。
- 天氣：用日期當亂數種子，任何裝置同一天結果一致。

### 3.2 時鐘作弊（Phase 1）

- 每次存檔記錄 `lastSeen`。若 `now < lastSeen − 5 分鐘`（時間被調回去），暫停所有成長，直到現實時間追上 `lastSeen`，並顯示溫和提示。
- 往前調時間在單機無法完全防止，Phase 1 接受；Phase 2 改用伺服器時間（見 `08 §3`）。

### 3.3 存檔風險：Safari 的 7 天清除（Phase 1 最大技術風險）

iOS／macOS 的 Safari 會刪除**超過 7 天沒互動的網站**所寫入的資料。對一年期的遊戲來說，玩家一週沒上線存檔就可能消失。對策：

| 對策 | 說明 |
|---|---|
| 引導安裝 PWA | 加到主畫面的 PWA 不受 7 天規則影響。第一天收成後、第三天各提示一次，並給裝飾獎勵 |
| `navigator.storage.persist()` | 請求持久化儲存 |
| 存檔碼 | 設定裡可匯出／匯入存檔（壓縮 JSON 或 QR code），每週提醒一次 |
| Phase 2 雲端存檔 | 根本解法 |

### 3.4 存檔格式

- 每 10 秒自動存檔，切換分頁（`visibilitychange`）時立即存。
- 存檔有 `schemaVersion`，每次改格式都要寫遷移函式，**不可讓舊存檔壞掉**。

## 4. 皮克斯風格渲染

| 項目 | 做法 |
|---|---|
| 色調映射 | AgX（或 ACES Filmic），sRGB 輸出，曝光可調 |
| 主光 | 暖色平行光（色溫約 5,500K），PCFSoft 柔和陰影 |
| 補光 | 半球光（天空藍、地面暖綠反彈）＋小型環境貼圖做柔和反射 |
| 輪廓光 | 角色與寵物加一盞弱的背光，讓剪影從背景跳出來 |
| 材質 | MeshStandardMaterial，粗糙度 0.5–0.8，飽和但不螢光；寵物毛與布料用 MeshPhysicalMaterial 的 sheen |
| 假次表面散射 | 葉子、皮膚、耳朵：在 shader 裡用 wrap lighting 讓暗部透出暖色 |
| 造型 | 全部圓角：RoundedBoxGeometry、倒角、膠囊體；誇張比例；避免銳利邊緣 |
| 環境光遮蔽 | N8AO：物件接地的陰影是「玩具模型感」的關鍵 |
| 後製 | 輕微 bloom（夜間燈光、夜間花）、暗角、依時段切換的色彩校正 LUT |
| 景深 | 高畫質才開：移軸（tilt-shift）效果，強化微縮感 |
| 動態 | 所有物件都有擠壓伸展、預備動作、回彈緩動（easeOutBack）；作物與草用頂點著色器做風吹搖擺 |

### 4.1 畫質分級

啟動後前 5 秒取樣 FPS，自動選級；玩家也可手動切換。

| 等級 | 裝置 | 陰影 | AO | 後製 | 像素比 |
|---|---|---|:-:|---|---:|
| 低 | 舊手機 | 1024，只有角色投影 | — | 無 | 1 |
| 中 | 一般手機 | 2048 | 半解析度 | bloom | 1.5 |
| 高 | PC、新手機 | 2048＋柔和 | 全解析度 | bloom＋LUT＋景深 | 2 |

## 5. 效能預算

以中階手機為基準（iPhone 12、Snapdragon 7 系列）：

| 項目 | 預算 |
|---|---|
| 幀率 | 目標 60 FPS，最低 30 FPS |
| Draw calls | < 150 |
| 三角面數 | < 300k |
| 貼圖記憶體 | < 64 MB |
| 首次下載 | < 8 MB（JS gzip < 800 KB），其他素材依需求載入 |
| 作物、雜草 | 用 InstancedMesh：同一作物同一成長階段 = 1 個 draw call |

## 6. 素材管線（混合）

| 類別 | 做法 | 工具 |
|---|---|---|
| 概念圖 | AI 生成主角、寵物、房屋的三視圖 | `codex exec` 內建 image_gen（不需要 API key） |
| 主角、寵物 | 依概念圖在 Blender 建模 → 綁骨架 → 做動畫 → 匯出 GLB（Meshopt 壓縮） | Blender（可用 blender-image-to-3d 流程） |
| 房屋 | 模組化部件（牆、屋頂、窗、門）在 Blender 做，程式組裝 5 個階段 | Blender ＋ 程式 |
| 作物 | **參數化作物生成器**：莖、葉、果實形狀＋顏色參數，自動產生 4 個成長階段 | 程式建模 |
| 雜草、石頭、樹樁、圍籬、小道具 | 程式建模＋隨機變化 | 程式建模 |
| UI 圖示 | 用 3D 模型在建置時**算圖成圖示**，風格和場景完全一致 | `scripts/render-icons` |
| 音效 | 自製或 CC0 素材，統一後製 | — |

## 7. DEV 微調工具（依全域開發準則，必做）

**開啟方式**：鍵盤 `` ` ``（Esc 下方）或 F2，或右下角齒輪（`D` 已被 WASD 移動使用）。只在開發版或網址加 `?dev=1` 時出現，正式版不打包。

| 分頁 | 可以調整的內容 |
|---|---|
| 版面 | 所有 HUD 元件的 x、y、寬、高、縮放、字級、顏色（顏色選擇器）、透明度、層級；**可直接用滑鼠拖曳 HUD 元件** |
| 場景 | 房屋、田區、果樹、寵物小屋、郵筒等物件，用 3D 操作把手（TransformControls）**直接拖曳**位置、旋轉、縮放 |
| 鏡頭 | FOV、距離範圍、俯角、跟隨阻尼 |
| 光影 | 各燈光的顏色、強度、角度；AO、bloom、曝光、LUT；**時段預覽**（清晨、黃金時刻、夜晚一鍵切換） |
| 時間 | 時間倍速 1× – 3600×、跳到下一個季節、跳到指定日期、跳到晚上、觸發下雨／下雪／彩虹 |
| 狀態觸發 | 作物立即成熟、生成 N 株雜草、升級、寵物成長過場、節慶開始、季節切換過場、回流禮、施工完成 |
| 寵物 | 親密度、心情、飽足、成長階段、強制播放任一動畫 |
| 經濟 | 加金幣、XP、材料；直接設定等級 |
| 版面切換 | PC、Mobile、Tablet 三種版面分開調整、分開匯出 |

- **所有調整即時生效**，不需要按「套用」。
- **💾 匯出**：把目前數值輸出成 JSON（複製到剪貼簿＋下載檔案）。你調好後跟我說「鎖定」，我把數值寫回 `src/layout/` 和資料表，再提交。
