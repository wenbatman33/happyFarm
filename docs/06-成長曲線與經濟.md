## 1. 設計原則

| 原則 | 說明 |
|---|---|
| 沒有付費貨幣 | 所有東西都用遊戲內資源取得 |
| 一年節奏 | 一般玩家約第 387 天到 Lv100 |
| 主動遊玩有獎勵，但不能無限刷 | 短作物單位時間效率高；**休息加成**讓「每天回來」比「一次刷很久」划算；季節與節慶內容用日曆鎖住 |
| 產出與消耗平衡 | 每個季度前跑一次經濟模擬，金幣產出和消耗的比例維持在 0.9–1.1 |

## 2. 等級曲線

### 2.1 公式

```
升到下一級所需 XP：XP_next(L) = ceil(300 + 42 × L^1.72)
一般玩家每日 XP（模擬假設）：DailyXP(L) = 2400 × (1 + 0.055 × L)
```

一般玩家的定義：每天上線 3 次、合計約 20 分鐘；等級越高田地越多、作物越高級，所以每日 XP 會跟著成長。

### 2.3 XP 來源

| 來源 | XP | 約佔每日比例 |
|---|---|---:|
| 收成 | 見 §4 公式 | 60% |
| 訂單 | 訂單內作物 XP 總和 × 1.5 | 20% |
| 除草、清荒地 | 每株 3–8、每個障礙物 5–15 | 8% |
| 加工 | 原料 XP 總和 × 0.5 | 7% |
| 每日任務 | 每項 = 當級 XP_next 的 2% | 5% |

### 2.4 休息加成（Rested XP）

- 離線每小時累積 `DailyXP(L) × 5%`，最多累積到 `DailyXP(L) × 150%`（約 1.5 天份）。
- 有加成時收成 XP ×2，多出來的部分從加成池扣除，扣完就恢復正常。
- 效果：每天回來 2–3 次的玩家，進度會比一次連刷 2 小時的玩家更好。

## 4. 作物經濟公式

```
t = 成長時間（分鐘）
種子價格   Seed(t)   = round(2 + 2 × t^0.55)
售價       Sell(t)   = Seed(t) + round(4 + 3 × t^0.55)
收成 XP    XP(t)     = round(2 + 3 × t^0.5)
```

## 7. 訂單與加工

### 7.1 訂單

```
訂單金幣 = Σ（作物售價 × 數量）× 1.4
訂單 XP  = Σ（作物 XP × 數量）× 1.5
```

- 需求只會出現玩家已解鎖、且當季可種的作物。
- 每 2 小時可以免費跳過 1 張訂單。

### 7.2 加工坊（Lv15）

```
成品售價 = Σ 原料售價 × 1.8
加工 XP  = Σ 原料 XP × 0.5
加工時間 = 原料中最長成長時間 × 0.5（最多 4 小時）
```

| 配方範例 | 原料 |
|---|---|
| 麵粉 | 小麥 × 3 |
| 麵包 | 麵粉 × 2＋甘蔗 × 1 |
| 草莓果醬 | 草莓 × 4 |
| 番茄醬 | 番茄 × 4 |
| 春茶罐 | 春茶 × 3 |
| 南瓜派 | 南瓜 × 1＋麵粉 × 2 |

加工欄位：2 格 → 4 格（Lv40）→ 6 格（Lv70）。
